# App icon

`lucide-braces.svg` is the downloaded Lucide `braces` icon (v1.31.0):
https://raw.githubusercontent.com/lucide-icons/lucide/1.31.0/icons/braces.svg

`../icon.svg` uses its brace paths in a CP Test Studio badge. The Lucide license is included in `LUCIDE-LICENSE.txt` and packaged with the app.
